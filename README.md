# Teyvat EliteDB

原神の精鋭狩りRTA記録を、ランキングと条件検索の両方から探せるようにする記録DBのUI/UXプロトタイプです。

このプロジェクトは、精鋭狩りRTAの記録を「最速順に並べる」だけでなく、キャラ・編成・コスト・カテゴリ・期間などの条件から探せるようにすることで、走者の試行錯誤や多様な編成の価値を見つけやすくすることを目的としています。

現在は、採用・運用形態が確定したサービスではなく、精鋭狩りRTAの記録の見せ方・探し方・残し方を検証するためのプロトタイプです。
現在はUI/UX検証用プロトタイプで、表示している記録データはモックデータです。

## このプロジェクトで目指していること

Teyvat EliteDB が目指しているのは、精鋭狩りRTAの記録をより見つけやすく、比較しやすく、残しやすくすることです。

精鋭狩りRTAには、純粋な最速タイムを詰める面白さがあります。
その競技性は残すべきものだと考えています。

同時に、現在の記録の見え方では、最速編成以外の記録、低コスト編成、特定キャラを軸にした編成、過去環境の記録が埋もれやすいという課題があります。

このサイトでは、ランキングを「共通の舞台」として残しつつ、条件検索を「自分に近い記録・参考にしたい記録を探す場所」として分けて設計しています。

## 背景

このプロジェクトは、Rさんによる精鋭狩りRTA記録サイトの問題提起を出発点の一つとしています。

[https://note.com/radicial/n/n01ed1ef84847](https://note.com/radicial/n/n01ed1ef84847)

この記事では、既存の記録サイトでは編成情報が見えにくく、キャラクター別・編成別に記録を探しにくいことが課題として指摘されています。

Teyvat EliteDB は、その問題提起に対して、UI/UXプロトタイプという形で一つの回答案を作ることを目的としています。

記事内のUI案をそのまま再現することが目的ではありません。
精鋭狩り界隈を長期的により良くするには、どのような記録の見せ方・探し方・残し方が必要かを検証するためのプロトタイプです。

## 解決したい課題

### 1. タイムだけで記録の価値が決まりやすい

最速タイムは重要です。
ただし、タイムだけを基準にすると、キャラや編成の工夫、低コストでの挑戦、過去環境の記録が見えにくくなります。

このサイトでは、タイムランキングに加えて、キャラ・編成・コスト・カテゴリなどの条件から記録を探せるようにします。

### 2. 編成情報が一覧で見えにくい

精鋭狩りRTAでは、どのキャラを使ったか、どの役割で使ったか、どの程度の凸・武器環境だったかが重要です。

記録カードや詳細ページでは、タイムだけでなく編成・キャラ・武器・凸・カテゴリなどの情報を見やすく表示することを目指しています。

### 3. 自分に近い記録を探しにくい

最上位の記録だけを見ても、自分の手持ちやプレイ環境とは大きく離れていることがあります。

このサイトでは、キャラ・編成・コスト・カテゴリ・期間・タグなどから、自分に近い記録や参考にしやすい記録を探せるようにします。

### 4. 非メタ編成や過去編成が埋もれやすい

同じ走者でも、違う編成で走った記録には別の価値があります。

このサイトでは、最速記録だけでなく、編成ごとの試行錯誤を記録として残し、後から探せるようにすることを目指しています。

## 主な画面・機能

### ランキング

共通条件で記録を並べる、競技性の中心となる画面です。

ランキングは、個人の検索条件によって自由に崩すのではなく、共通の基準で見られる場所として扱います。

想定している要素:

- 総合ランキング
- カテゴリ別ランキング
- コスト別TOPプレイヤー
- キャラ別・編成別の代表記録
- 記録カード上での編成表示

### 条件から記録を探す / Library

自分の目的に合う記録を探すための画面です。

ランキングが「共通の舞台」だとすれば、Library は「参考記録を探す場所」です。

想定している検索軸:

- キャラ・編成
- 凸・武器
- カテゴリ・期間
- タグ
- コスト
- プラットフォーム
- バージョン
- 使用キャラの含む / 除外

### 記録詳細

1つの記録を深く見るための画面です。

想定している要素:

- タイム
- 走者名
- 使用編成
- キャラごとの役割
- 武器・凸・精錬
- 動画URL
- カテゴリ
- コスト
- バージョン
- メモ
- 類似記録
- 比較候補への追加

### 比較ビュー

複数の記録を並べて比較するための画面です。

精鋭狩りRTAでは、単純なタイム差だけでなく、編成・キャラ・凸・武器・ルート・環境差を見比べることが重要です。

比較ビューでは、参考にしたい記録同士を並べて、違いを見やすくすることを目指しています。

### 記録投稿フロー

記録を投稿するための画面です。

現在はプロトタイプ段階であり、投稿項目や確認フローは今後の意見を踏まえて調整する予定です。

想定している入力項目:

- 走者名
- タイム
- 動画URL
- カテゴリ
- プラットフォーム
- バージョン
- 使用キャラ
- 武器
- 凸
- 精錬
- 役割
- メモ

## 設計方針

### ランキングと条件検索を分ける

このプロジェクトでは、ランキングと条件検索を同じものとして扱いません。

ランキングは、共通の基準で競うための場所です。
条件検索は、自分に合った記録や参考記録を探すための場所です。

両方を分けることで、競技性と探索性を両立させることを目指しています。

### 最速だけを否定しない

このサイトは、最速を目指す文化を否定するためのものではありません。

精鋭狩りRTAにおいて、タイムを詰めることは中心的な価値です。
そのうえで、最速以外の記録にも意味がある状態を作りたいと考えています。

### 推しキャラ紹介サイトにはしない

キャラへのこだわりは大切ですが、このサイトは単なる推しキャラ紹介サイトではありません。

記録、編成、条件、タイム、比較、研究のためのDBとして設計しています。

### 完成形を押し付けない

現在のUIは、採用が決まった完成形ではありません。

Rさんの記事の問題定義に対する回答案として、実際に触れる形のプロトタイプを作り、走者や界隈の意見を受けながら改善することを前提としています。

## 今後の予定

### Phase 1: UI/UXプロトタイプ

現在のフェーズです。

目的:

- 主要画面を触れる形にする
- 記録の見せ方を検証する
- ランキングと条件検索の分離を確認する
- 記録詳細・比較・投稿導線をつなげる
- Rさんや精鋭狩り走者に見せられる状態にする

### Phase 2: 最小DBループの実装

投稿された記録が保存され、一覧と詳細に反映される最低限の流れを作ります。

実装予定:

- Supabase連携
- 記録投稿
- 記録一覧取得
- 記録詳細取得
- 条件検索
- モックデータから実データへの移行

### Phase 3: コミュニティフィードバック

プロトタイプを精鋭狩り走者に見てもらい、分類・検索条件・UI・投稿項目を調整します。

確認したいこと:

- 必要なカテゴリ
- 記録として残すべき情報
- 採用すべき検索条件
- 不要なUI
- 誤解を生みやすい表示
- 実運用時に必要なルール

### Phase 4: 運用設計

実際に使う場合の運用方法を考える段階です。

検討項目:

- 記録の投稿ルール
- 動画確認
- 重複記録の扱い
- 同一走者・別編成の扱い
- 管理者権限
- 不正対策
- 非公式サイトとしての表記
- 長期運用コスト

## このプロジェクトの立ち位置

Teyvat EliteDB は、原神公式・HoYoverse・miHoYoとは関係のない非公式プロジェクトです。

また、既存の記録サイトやコミュニティを置き換えることを目的としているわけではありません。

精鋭狩りRTAの記録をより探しやすく、比較しやすく、残しやすくするための補助的なDBとして検証しています。

外部の画像・ゲーム関連素材は、それぞれの権利者に帰属します。
