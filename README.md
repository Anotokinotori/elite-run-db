# Teyvat EliteDB (精鋭狩りRTA 記録データベース)

Teyvat EliteDB は、原神（Genshin Impact）の「精鋭狩りRTA」における、多様な編成と新しい遊び方を記録・共有するためのコミュニティ主導型データベースである。

現在、コンセプト実証のためのプロトタイプとして開発が進められている。

## 📖 プロジェクトが始まった背景

原神の精鋭狩りRTA界隈では、長らくSpeedrun.com (SRC) が主な記録サイトとして利用されてきた。しかし、ナタ環境以降、キャラクターの選択肢が爆発的に増えたことで、従来の「純粋なタイムの速さのみ」を競うSRCのシステムと、コミュニティの現状に大きなすれ違いが生じ始めている。

**現状の課題:**
1. **多様性の喪失:** タイムのみで順位が決まるため、特定の最強編成（メタ編成）以外の記録が下位に埋もれてしまい、新たな編成を開拓するモチベーションが削がれてしまう。
2. **「引かされる」環境への抵抗:** 最速を目指すためだけに、自分の好みではない強力なキャラクターを引かなければならないというプレッシャーがある。
3. **新規参入のハードル:** 「最速編成が組めないなら走る意味がないのでは？」という空気感が、界隈への新規参入を躊躇させている。

この状況に対し、界隈の走者であるR氏が「メインアタッカーごとに記録を分け、編成の多様性を評価できる独立したデータベースサイト」のコンセプトを提案した。
本プロジェクトは、そのアイデアに賛同し、「技術的なバックアッププラン」として水面下で始動したものである。

## 目指す完成形（本質的な目標）

このプロジェクトの本質的な目標は、**「より多くの人に、この精鋭狩り界隈へ入ってもらうこと」**である。

誰もが最速を目指す必要はない。推しキャラで走りたい人、低コスト編成で限界に挑みたい人、全く新しいネタ編成を開拓したい人。それぞれの「遊び方」が正当に評価され、記録として残り、誰かの参考になる場所を作ることを目指している。

**Teyvat EliteDB が提供する価値:**
- **どんなキャラ・凸環境でも参加できる:** メインアタッカー別、あるいはコスト別（Low / Middle / High / Unlimited）に記録を管理し、自分の手持ちで挑戦できる目標を提示する。
- **情報量の最大化:** 「あのキャラを使った編成はないか？」と探した時に、先人たちの試行錯誤の記録がすぐに見つかる「生きたデータベース」を構築する。
- **持続可能なゼロコスト運用:** 管理者やコミュニティに金銭的負担をかけず、長期的に安定稼働できるモダンな技術スタック（サーバーレス・無料枠の最大限活用）を採用している。

## 現在のステータス

- **Phase 1: プロトタイプ開発中** (現在)
  - UI/UXのコンセプト実証（React + Tailwind CSS + Vite）
  - モックデータを用いたフロントエンドの構築
- **Phase 2: バックエンド統合予定**
  - Supabaseを用いたデータベース構築とAPI連携
  - 記録の投稿・検索機能の実装

本プロジェクトは、運用費0円を目指す。

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS, shadcn/ui (予定), Lucide React
- **Backend/DB:** Supabase (PostgreSQL) - *導入予定*
